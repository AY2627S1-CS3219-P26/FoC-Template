Title: Forgotten password
Questions: I forgot my password. How do I reset my password? Is there a forgot password link? How do I recover my account?

The app does not have a forgot password or password reset feature at the moment. There is no reset link on the Log in page and no reset email. A password can only be changed while logged in, and changing it requires the current password. Administrators cannot set a new password for you in the app either. If you are still logged in on another device, you can change it there from the Profile page, but you still need the current password.
