Title: The admin console
Questions: How do I open the admin console? Where is the admin page? How do I become an administrator? What can administrators do? How do I leave the admin console?

The admin console is for accounts with the administrator role. The student app has no link to it, so go to /admin by typing the address. Its menu has Orders, Students, Reports, Disputes and Suppliers. Leave admin console returns to the student app. Accounts that are not administrators see the page "Administrator access required".

You cannot give yourself the administrator role. An existing administrator has to grant it.

Administrators list, edit and delete accounts, suspend accounts, change roles, decide reports, resolve disputes, and create, update or deactivate suppliers.
