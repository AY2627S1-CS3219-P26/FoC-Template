# Walking map of the NUS area

`nus-walk.graph` is the network of paths the supplier-service computes walking
routes on: about 6 x 6 km around NUS, from the campus and Prince George's Park
to Clementi, Dover, one-north and West Coast. `nus-walk.json` says which
OpenStreetMap data it was built from and when.
